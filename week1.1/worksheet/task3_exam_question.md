# Exam-style Question

## State two advantages of using version control when writing software.
---
1. An advantage of version control from the perspective of an individual programmer is that version control keeps prior working versions of git repositories. If you push a commit with broken code, it is possible to revert back to a working version. This is beneficial because it saves time for an individual programmer, especially in the context of larger codebases where it can be harder to diagnose issues.
---
2. An advantage of version control from the perspective of working in a team developing software is that developers can review changes made by others and track who is committing what. This way bugs can be identified by when or where they were introduced, and can be used to track contributions to check if everyone is contributing what they are supposed to be to a project.
---
